# Customer Segmentation Using K-Means Clustering

## Project Overview

This project uses K-Means Clustering in Python to segment customers based on their Annual Income and Spending Score. The objective is to identify distinct customer groups and generate actionable business insights for better marketing and customer targeting.

## Objectives

* Clean and prepare the customer dataset
* Perform Exploratory Data Analysis (EDA)
* Analyze customer income and spending behavior
* Apply K-Means Clustering
* Identify meaningful customer segments
* Visualize the customer clusters
* Generate business recommendations

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Dataset

The dataset contains customer information including:

* Customer ID
* Gender
* Age
* Annual Income
* Spending Score

For clustering, Annual Income and Spending Score were selected as the main features.

## Project Workflow

1. Load the dataset
2. Explore the dataset
3. Check for missing values
4. Check and remove duplicate records
5. Perform Exploratory Data Analysis
6. Select features for clustering
7. Apply K-Means Clustering
8. Visualize the customer segments
9. Analyze cluster characteristics
10. Generate business insights

## K-Means Clustering

K-Means is an unsupervised machine learning algorithm that groups similar data points into clusters.

In this project, the customers are divided into 5 clusters based on their Annual Income and Spending Score.

## Customer Segments

The clusters can be interpreted based on income and spending behavior, including:

* High-income, high-spending customers
* High-income, low-spending customers
* Low-income, high-spending customers
* Low-income, low-spending customers
* Average customers

## Business Insights

Customer segmentation can help businesses:

* Create targeted marketing campaigns
* Offer personalized discounts
* Identify high-value customers
* Improve customer retention
* Develop targeted loyalty programs
* Increase customer spending and engagement
